# Ant Game — Session Log (2026-05-01 through 2026-05-04)

## Overview

Built a complete ant colony simulation tycoon prototype from scratch over 3 days.
Started from an empty Rojo project scaffold, ended with a playable game featuring
19 source files, ~6,700 lines of Lua, 15 interconnected nodes, and 8 HUDs.

**Repo:** `AlphaRabbit-Games/Warren`, branch `v3.0`, path `Framework/v3/ant-game/`
**Rojo project:** `default.project.json`, name "AntGame"

## Architecture

All game logic is **tick-driven** from a single `GameClock` node (1 tick/sec).
No background threads — every system advances only when pulsed by the clock.
Nodes communicate via Warren IPC signals (FBP pattern). Server-side simulation,
client-side HUDs with cross-domain signal routing.

### Instance creation order (matters for init signals):
```
GameManager → CommandManager → GameClock → FoodSource → FoodHopper → EggClutch → Colony → spawnQueen → spawnWorker
```

## Systems Built

### 1. Unified Ant Model (ColonyNode)
- Queen and workers share same base: energy, metabolism, bite cycle, starvation
- Queen has "Lay Eggs" command, workers have class-based commands
- All timing driven by GameClock pulse
- Metabolism: 1 energy/tick working, 0.5x when idle
- Starvation: 10 ticks at 0 energy = death
- Queen death triggers game over signal

### 2. Food Economy
- **5 food tiers:** crumb, seed, insect, fruit, honeydew
- **Distance-based:** closer food = less travel time, further = more
- **Energy formula:** `colonySize * metabolism * (distance*2 + cooldown) * difficulty * nutritionTier`
- **Exploration:** workers explore closest-first, discover sources
- **6 gather strategies:** closest, largest, best energy, efficiency buff, endurance buff, egg buff
- **Travel time:** `distance * 2` ticks round trip

### 3. Blended Pantry (FoodHopperNode)
- Tracks stock per food type (not just a single number)
- Energy per bite = `totalStock / colonySize` (larger colonies get less per bite)
- Proportional drain across food types
- Finite capacity, upgradeable to 1000

### 4. Food Buff System
- Buff power inverse to nutrition tier (crumbs buff hard, honeydew barely)
- Crumb→efficiency(50%), Seed→endurance(40%), Insect→all(30%), Fruit→eggProduction(20%)
- Buffs computed from pantry mix ratios, applied as multipliers on base stats
- `effectiveStat = baseStat * (1 +/- buff)` — live, no stacking/timers
- Ants track base stats separately from effective stats

### 5. Difficulty Scaling (GameManagerNode)
- Starting multiplier: 3.0 (easy)
- Decays 25% per egg hatch, floor 0.50
- Affects energy per gather on newly spawned food sources
- Existing sources keep their original energy values

### 6. XP System
- +1 XP per completed explore or gather trip
- Spent on queen attributes: egg rate, egg efficiency, hatch endurance, hatch efficiency
- Level cost escalates: `baseCost * 1.25^level`
- XPHUD shows current values and next-level preview
- XP also used for class reclass and rebirth

### 7. Worker Class Tree (ClassTree.lua)
- Data-driven tree structure — adding classes = adding rows
- 12 classes across 3 tiers:
  - **Tier 0:** Worker (base, unspecialized)
  - **Tier 1:** Explorer, Gatherer, Builder
  - **Tier 2:** Scout, Tracker, Forager, Harvester, Selector, Digger, Mason, Stockpiler
- Each class has one command, rebirth cost, and stat bonuses
- Default class from pantry buff profile at hatch (fallback: explorer)
- Free reclass on first task assignment
- Paid reclass (1 XP base, +25%/reclass) after locked
- Rebirth into tier 2 costs XP, grants permanent stat bonuses
- Stat requirements removed from tier 2 (pending per-ant upgrade system)

### 8. Queen Egg Laying
- Gestates while energy >= eggEnergyCost, lays when counter hits eggInterval
- After laying: cooldown (20 ticks), eats to recover
- Exits cooldown when energy reaches 100% → resumes laying
- If timer expires without reaching full → goes idle (player must re-assign)
- Egg cost and interval modifiable via XP queen upgrades and food buffs

### 9. Egg Clutch (EggClutchNode)
- Capacity 5, upgradeable to 50 (by builder ants)
- Eggs hatch after 120 ticks
- If clutch full when queen lays → egg discarded
- Hatching spawns new worker in ColonyNode

### 10. Command System (CommandManagerNode)
- Class-aware: shows only commands valid for selected ant's class
- Shows rebirth options with XP costs
- Shows reclass options to tier 1 classes
- Task caps: upgrades capped at 2 per target, everything else 999
- Validates chamber constraints (clutch/pantry max capacity)
- Routes through to ColonyNode, deducts XP via GameManagerNode

## Gameplay Loop

1. **Start:** Queen + 1 Explorer worker, empty pantry
2. **Explore:** Send worker to find food (closest first, distance-based travel time)
3. **Reclass:** Spend 1 XP to reclass explorer → gatherer
4. **Gather:** Worker gathers food, deposits in pantry
5. **Feed:** Queen eats from pantry, builds energy for egg laying
6. **Lay:** Queen gestates and lays egg into clutch
7. **Hatch:** Egg hatches after 120 ticks → new worker spawns
8. **Expand:** Assign workers to gather/explore/build, upgrade pantry/clutch
9. **Specialize:** Spend XP on queen upgrades or worker rebirths
10. **Balance:** Manage food income vs colony consumption

## Difficulty Analysis

From playtesting:
- **First run (pre-balance):** Colony of 45, 54 eggs, ran ~40 min on autopilot before collapse
- **With difficulty decay:** Colony peaked at ~18, oscillated between growth and starvation
- **Current state:** Still feels easy once past the first 2-3 minutes
- **Root cause:** Only one difficulty axis (food). No external pressure after stabilization.

### Discussed but not yet implemented:
- Colony-size-based metabolism scaling (exponential food demand)
- Tunnel system (expansion treadmill)
- PvP raiding (endgame pressure)
- Per-ant individual upgrades (spend XP on specific workers)
- Mating system (queen rebirths based on worker class pairing)
- Robux monetization (parallel currency to XP for same upgrades)

## Known Issues

1. **IPC cycle detection** may block ColonyNode→FoodSourceNode→ColonyNode round-trip signals in some cases
2. **QueenNode.lua and WorkerNode.lua** are dead files (superseded by ColonyNode) — should be deleted
3. **Colony list gets long** — no scrolling pagination or filtering for large colonies
4. **No save/load** — colony resets on server restart
5. **Food sources can all exhaust** in mid-range before far sources are reachable
6. **Existing ants don't benefit from hatch endurance upgrades** (only new hatchlings)
7. **HUD positions hardcoded** with pixel offsets — will break on different screen sizes

## Design Decisions Log

| Decision | Rationale |
|----------|-----------|
| Tick-driven, no threads | Deterministic, debuggable, FBP-aligned |
| Unified queen/worker model | Same energy/metabolism/starvation — class determines abilities |
| Food buff inverse to energy | Creates strategic tension: junk food buffs, premium food feeds |
| Distance-based food | Natural progression curve: nearby easy, far rewarding |
| Break-even formula | Mathematical foundation for difficulty — not arbitrary numbers |
| Data-driven class tree | Adding content = adding rows, not code changes |
| XP as dual currency | Same upgrades via XP (free grind) or Robux (paid shortcut) |
| Blended pantry | Food strategy is continuous — what you store determines colony buffs |
| Idle metabolism 0.5x | Unassigned ants drain slower — breathing room for management |
| Queen auto-idles when unfed | Forces player to manage food before egg production |
